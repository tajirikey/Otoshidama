# お年玉管理アプリ

2つのアカウント（さや・せいや）でお年玉の入金・支出を管理できるWebアプリです。

## 特徴

- **夫婦で共有**: サーバー（Vercel KV）で一元管理。複数端末から同じデータを閲覧・編集
- **2アカウント対応**: さやとせいやのお年玉を別々に管理
- **期間フィルター**: 今年・今月・全期間での集計が可能
- **残額メーター**: 視覚的に残額を確認できる
- **プレビュー機能**: 支出入力時にあといくら残るかをリアルタイム表示
- **パスワードロック**: 環境変数で管理する共有パスワードでログイン
- **PWA対応**: iPhoneのSafariで「ホーム画面に追加」するとアプリのように使えます

## 技術スタック

- Next.js 14 (App Router)
- React 18
- TypeScript
- Vercel KV (Upstash Redis)

## デプロイ方法（Vercel）

### 1. リポジトリを Vercel にインポート

1. このリポジトリをGitHubにプッシュ
2. [Vercel](https://vercel.com)で「New Project」からインポート
3. Framework Preset は `Next.js`、その他の設定はデフォルトでOK

### 2. Vercel KV を作成

1. プロジェクトの「Storage」タブを開く
2. 「Create Database」→ 「KV」（Upstash Redis）を選択
3. 作成後、プロジェクトに「Connect」する
4. これで以下の環境変数が自動で注入されます：
   - `KV_REST_API_URL`
   - `KV_REST_API_TOKEN`
   - （その他 `KV_URL` などもセット）

### 3. パスワードを環境変数に設定

プロジェクトの「Settings」→「Environment Variables」で以下を追加：

| Name | Value |
|------|-------|
| `APP_PASSWORD` | 共有したいパスワード文字列 |

すべての環境（Production / Preview / Development）にチェックを入れて保存。

### 4. デプロイ

設定後、再デプロイすれば反映されます。発行されたURLにアクセスし、ログイン画面で `APP_PASSWORD` に設定したパスワードを入力するとアプリが使えます。

## ローカル開発

```bash
npm install
npm run dev
```

ローカル開発で本物のサーバーストレージを使いたい場合は、リポジトリ直下に `.env.local` を作成：

```
APP_PASSWORD=your-password
KV_REST_API_URL=https://...
KV_REST_API_TOKEN=...
```

Vercel KV の値は Vercel ダッシュボードの「.env.local」コピー機能から取得できます。

`KV_REST_*` が未設定の場合は同一プロセス内のメモリにフォールバックします（再起動・サーバーレス関数の別インスタンスでは消えます）。

## 使い方

1. **ログイン**: 共有パスワードを入力
2. **アカウント切り替え**: 「さや」「せいや」ボタンでアカウントを切り替え
3. **入金追加**: 「入金を追加」ボタンから、お年玉の入金を記録
4. **支出追加**: 「支出を追加」ボタンから、使ったお金を記録
   - 金額を入力すると、使った後の残額がプレビュー表示される
5. **明細確認**: 「一覧を見る」で全ての取引を確認
6. **複数端末で共有**: 同じパスワードでログインすればどの端末からも同じデータを編集可能（5秒ごとに自動同期）
